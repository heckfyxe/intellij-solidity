Reports language features that were removed in a Solidity version guaranteed by the file's pragma solidity. Files without a version pragma are not checked.

Removed in 0.5.0: throw, var, the years unit, sha3, suicide, callcode, msg.gas, block.blockhash, unary +, functions without an explicit visibility, functions named like their contract (old-style constructors), events invoked without emit and address members on contract types (this.balance).

Removed in 0.7.0: now, the szabo and finney denominations and the .value(...)/.gas(...) call syntax.

Removed in 0.8.0: the byte type.

See the breaking changes pages of the Solidity documentation.
