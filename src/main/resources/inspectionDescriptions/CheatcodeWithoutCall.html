Reports vm.expectRevert(...) and vm.prank(...) in Foundry tests when no external call follows them in the test function. Both cheatcodes apply to the next call the test makes; a revert in an internal function or an expression happens at the test's own depth, so expectRevert doesn't catch it, and a prank followed by no call changes nothing.

Other cheatcode calls between the cheatcode and the call are skipped. Internal functions are followed into their bodies, and a statement with a call that can't be resolved (or inline assembly) is never reported.

expectRevert is also reported when a statement before the call always reverts in the test itself: revert, require(false), or an internal function that reverts before it can return.

vm.expectRevert(Vault.Empty.selector);
_withdraw(1); // reported when _withdraw doesn't call the vault and nothing after it does
