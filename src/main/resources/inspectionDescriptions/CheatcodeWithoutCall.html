Reports vm.expectRevert(...) and vm.prank(...) in Foundry tests when the next statement makes no external call. Both cheatcodes apply to the next call the test makes; a revert in an internal function or an expression happens at the test's own depth, so expectRevert doesn't catch it, and a prank followed by no call changes nothing.

Other cheatcode calls between the cheatcode and the call are skipped. Internal functions are followed into their bodies, and a statement with a call that can't be resolved (or inline assembly) is never reported.

vm.expectRevert(Vault.Empty.selector);
_withdraw(1); // internal: reported unless it calls the vault
vault.withdraw(1); // fine
